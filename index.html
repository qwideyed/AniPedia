Manual Episode & Entry Logging Format

Because you are curating and entering all records by hand, AniPedia uses this structured schema. Copy this standard layout to draft new episodes into the catalog: 

{
  "id": "series-slug",
  "title": { "romaji": "Title", "native": "日本語" },
  "type": "anime", // anime, animation, manga, adult
  "isAdult": false,
  "episodes": [
    {
      "ep": 1,
      "title": "Episode Title",
      "recap": "Step-by-step narrative breakdown...",
      "keyEvents": ["Event A", "Event B"],
      "castFeatured": ["Character ID"]
    }
  ]
}
